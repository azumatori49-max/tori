# グルメサイト コース入力テキスト生成

ユーザーが貼り付けたコース原文(幹部LINEで届いた文章)から、食べログ用・ホットペッパー用の入力テキストを生成する。

## 前提知識(必ず読む)

1. `ops/02-gourmet-site/サイト別仕様メモ.md` を読み、各サイトの文字数制限・項目対応を確認する
   - 未記入(【　】のまま)の項目は制限不明として扱い、出力に「※上限は管理画面で要確認」と注記する
2. `ops/02-gourmet-site/更新チェックリスト.md` の「短縮のときに削る優先順位」に従う

## 手順

1. 原文から以下を抽出する:コース名 / 価格(税込・税抜) / 品数 / 料理内容(品目リスト) / 飲み放題 / 利用可能曜日・期間 / 利用人数 / 予約条件 / アピール文
2. 抽出結果を表で提示し、原文に無い項目は「原文に記載なし」と明示する(勝手に補完しない)
3. サイトごとに、項目別のコピペ用テキストを生成する

## 短縮ルール(厳守)

- 削る順:①修飾語(「当店自慢の」等)→ ②料理の細かい説明 → ③重複情報
- **絶対に削らない・変えない**:価格 / 品数 / 飲み放題の有無と時間 / 曜日・期間 / 人数 / 予約条件 / アレルギー・注意書き
- 数字の表記(税込・税抜、品数)は原文のまま。判断に迷う場合は勝手に決めずユーザーに確認する

## 出力フォーマット

```
## 抽出結果
(項目と値の表)

## 食べログ用
▼コース名(◯文字 / 上限◯文字)
(テキスト)
▼説明文(◯文字 / 上限◯文字)
(テキスト)
▼料理内容
(テキスト)

## ホットペッパー用
(同上)

## 整合性チェック表
| 項目 | 食べログ | ホットペッパー | 一致 |
(価格・品数・飲み放題・曜日・人数・予約条件を比較)

## 入力後のチェックリスト
(更新チェックリスト.md のBセクションを要約して提示)

## 幹部LINE用 完了報告文
(入力完了後にそのまま送れる文面)
```

- 各テキストには実際の文字数を明記する。上限を超える場合は超過分を示し、短縮案を提示する
