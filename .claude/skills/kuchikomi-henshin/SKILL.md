# Google口コミ返信ドラフト生成

ユーザーが貼り付けた口コミ(1件でも複数件でもよい)に対して、返信文の下書きを生成する。

## 前提知識(必ず読む)

- 返信のトーン基準・構成・カテゴリ別テンプレは `ops/01-google-kuchikomi/返信テンプレ.md` に従う
- 判断フロー(社内共有の要否)は `ops/01-google-kuchikomi/運用手順.md` の「判断フロー(星1〜2)」に従う
- 両ファイルを読んでから返信文を作成すること

## 手順

1. `ops/01-google-kuchikomi/返信テンプレ.md` と `ops/01-google-kuchikomi/運用手順.md` を読む
2. 貼り付けられた口コミを1件ずつ分類する(接客/料理/待ち時間/価格・量/環境/会計/異物・体調不良/事実誤認/内容なし)
3. 各件について以下を出力する

## 出力フォーマット

複数件の場合は番号を付けて、この形式で全件出力する:

```
【1件目】星◯ / 分類:◯◯ / 社内共有:不要 or 【要共有・理由】

▼返信文(そのままコピーして投稿できる形)
(返信文)
```

## 厳守事項

- 返信は4〜6文。言い訳・反論・責任転嫁をしない
- 金銭補償の約束、従業員の個人名、お客様の特定につながる情報は書かない
- 異物混入・体調不良・会計トラブルは「事実確認中」の定型のみ+【即日共有】フラグを必ず付ける
- 口コミの内容に1文だけ具体的に触れて、定型文っぽさを消す
- 全件の出力後、【要共有】の案件だけをまとめた「幹部LINE共有用の文面」(運用手順.md の共有フォーマット準拠)も生成する
- 電話番号などユーザーしか知らない情報は `◯◯` のままにして、最後に「◯◯を埋めてください」と一覧で伝える
