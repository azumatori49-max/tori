# 応募者対応 LINE文面生成

応募者対応の各場面に合ったLINE文面を生成する。

## 前提知識(必ず読む)

- 文面のベースは `ops/04-obosha-taio/LINEテンプレ集.md` のテンプレ1〜7に従う

## 手順

1. ユーザーの依頼から、場面を特定する:
   - 面接担当者への日程確認(テンプレ1)
   - 応募者への候補日提示(テンプレ2)
   - 確定連絡(テンプレ3)
   - リマインド(テンプレ4)
   - 再調整(テンプレ5)
   - 前日リマインド(テンプレ6)
   - 担当者への確定共有(テンプレ7)
2. 伝えられた情報(名前・店舗・職種・媒体・候補日時など)をテンプレに埋め込む
3. そのままコピーして送れる形で出力する

## 厳守事項

- 伝えられていない情報は `◯◯` のままにして、最後に「埋めてください」と一覧で伝える。勝手に日時や場所を創作しない
- 複数の応募者をまとめて依頼された場合は、番号を付けて全員分を出力する
- トーンはテンプレ準拠(丁寧だが硬すぎない。応募者向けは「!」を使った親しみやすい文体)
