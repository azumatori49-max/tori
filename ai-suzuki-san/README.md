# AI鈴木さん 🤖

入社手続き・給与手続きの書類に不備があったとき、
**鈴木さん → エリアマネージャー → 本人** という遠回りな連絡を、
**鈴木さん → AI鈴木さん → 本人** に短縮するLINEボットです。

既存のLINE公式アカウント（Poster連携済み・全従業員が友だち登録済み）の上で動きます。

## 仕組み

```
鈴木さん ──LINEで不備を報告──▶ AI鈴木さん（このサーバー + Claude API）
                                     │
                                     ├─ 不備内容を分かりやすい文面にして本人へLINE通知
                                     ├─ 本人からの質問にその場で回答・再提出まで案内
                                     ├─ 放置されたら自動リマインド（既定: 48時間ごと×2回）
                                     └─ 解決したら鈴木さんへ完了報告
```

- 従業員からのメッセージは **Posterの「LINE-Webhook全転送」** でこのサーバーに届きます
- 返信は LINE Messaging API（プッシュ送信）で、いつもの公式アカウントから届きます
- **対応中の案件がある従業員にだけ** AIが反応します。それ以外のメッセージには一切反応しないので、社内報などの既存運用と衝突しません
- 案件の状態に合わせてPosterのタグ（例:「不備対応中」）を付け外しするので、鈴木さんはPoster管理画面からも状況を確認できます

## 鈴木さんの使い方

普段使っているLINEから、公式アカウントにこう送るだけです：

> U1234...（PosterでコピーしたLINE UID）の山田太郎さん、雇用契約書の住所欄が未記入。今週金曜まで

AI鈴木さんが内容を確認して本人に通知し、以後のやり取りを引き受けます。
その他にできること：

| 送るメッセージ例 | 動作 |
|---|---|
| 「対応中の案件を教えて」 | 案件一覧を表示 |
| 「#a1b2c3d4 OK」 | 案件を完了にして本人にお礼を送信 |
| 「#a1b2c3d4 の人に◯◯と伝えて」 | 本人に追加メッセージを送信 |

従業員が「提出しました」と言うと、案件は「確認待ち」になり鈴木さんに確認依頼が届きます。

## セットアップ

### 1. Poster側の設定（管理画面）

1. **APIクライアントの作成** — 開発者向け機能からAPIクライアントを作成し、認証情報を取得（APIプラン契約済みなら追加費用なし）
2. **LINE-Webhook全転送の設定** — 転送先URLにこのサーバーの `https://<ドメイン>/webhook/line` を設定
3. **タグの作成**（任意） — 「不備対応中」タグを作成しておくと、案件の状態がPoster管理画面からも見える

参考: [Poster Developer Documents](https://poster.ooo/poster-dev-doc/mainpage/) /
[LINE-Webhook全転送](https://poster.ooo/poster-dev-doc/webhook-all-transfer/)

> ⚠️ `src/poster.ts` のタグAPIのエンドポイントパスは雛形です。Poster開発者ドキュメントの実際の仕様に合わせて調整してください（タグ同期は失敗しても業務フローは止まりません）。

### 2. LINE側の設定

- LINE Developersコンソール（Posterに登録したのと同じチャネル）から
  **長期チャネルアクセストークン** と **チャネルシークレット** を取得

### 3. このサーバーの起動

```bash
cd ai-suzuki-san
npm install          # または pnpm install
cp .env.example .env # 値を埋める
npm run dev          # 開発時。 本番は npm start
```

必須の環境変数：

| 変数 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude APIキー（[console.anthropic.com](https://console.anthropic.com)で取得） |
| `ADMIN_LINE_USER_IDS` | 鈴木さんのLINE UID（Poster管理画面の友だち検索で確認） |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE長期チャネルアクセストークン |
| `LINE_CHANNEL_SECRET` | LINEチャネルシークレット（署名検証用） |

デプロイ先は常時起動できるところならどこでも（Render / Railway / fly.io / VPSなど、月数百円〜）。
HTTPSで外部からアクセスできるURLが必要です。

### 4. 動作確認

1. 鈴木さんのLINEから公式アカウントに「テスト」と送る → AI鈴木さんが応答すれば管理者判定OK
2. テスト用の従業員UID（自分のサブアカウント等）で不備を登録してみる
3. 従業員側から質問→「提出しました」→ 鈴木さんに確認依頼が届く、の一連を確認

## 運用コストの目安

- Claude API: この規模（不備対応が月数十件）なら月数百円〜数千円程度
- サーバー: 月0円〜数百円（無料枠のあるPaaSで足りる規模）
- Poster: 既存のAPIプラン内（追加費用なし）

## 個人情報の扱い

- マイナンバー・口座番号そのものはAIのメッセージに含めない設計です（プロンプトで明示的に禁止）。
  案内は「◯◯欄をご記入ください」のように項目名ベースで行います
- 従業員から画像・ファイルが送られた場合、AIは中身を見ずに「受領した」ことだけを鈴木さんに連携します
- 会話履歴・案件データは `data/store.json` にローカル保存されます。サーバーのアクセス管理をしてください

## 構成

```
src/
├── index.ts    # Webhookサーバー本体 + リマインドループ
├── ai.ts       # Claude連携（鈴木さん用/従業員用の2つの会話フロー + ツール）
├── store.ts    # 案件・会話履歴の永続化（JSON）
├── line.ts     # LINE Messaging API（送信）
├── poster.ts   # Poster API（タグ同期・ベストエフォート）
├── verify.ts   # Webhook署名検証（HMAC-SHA256）
└── config.ts   # 環境変数
```
