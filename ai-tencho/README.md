# AI店長（店長サポートAI）

新規出店1店舗に導入する完全自走型のAI店長システム。
**数字を見る仕事をAIが引き受けるので、店長は人を見てください。**

- 判定は機械（決定論的ルールエンジン）、表現はAI（Claude）、決定は人（店長）
- 頭脳は GAS（5分トリガー）。店内モニターは Firebase を購読して表示とMP3再生のみ
- スタッフへの指示は店長がLINEで承認したタスクのみ配信される

| ディレクトリ | 内容 |
|---|---|
| `gas/` | Google Apps Script（clasp 管理）。判定・生成・音声・配信・監視のすべて |
| `display/` | 店内モニター（Chrome kiosk 用静的HTML。CSSのみの球で状態表示） |
| `docs/` | 判定ルール・セットアップ手順・未確定事項・仕様からの変更点 |
| `test/` | 純関数（判定・基準値・スケジュール・禁止語）の単体テスト |

```bash
# テスト実行
cd ai-tencho && npm test

# デプロイ手順
docs/SETUP.md を参照
```

設計の全体像は `CLAUDE.md`、仕様書から意図的に変えた点は `docs/CHANGES_FROM_SPEC.md` を参照。
