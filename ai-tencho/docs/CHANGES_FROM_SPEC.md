# 仕様書からの変更点

実装にあたり、技術的に誤り・危険と判断して変えた箇所。承認されない場合は差し戻し可能なように、変更はすべてここに集約する。

## 1. Claude のモデルIDを `claude-sonnet-5` に変更

仕様書指定の `claude-sonnet-4-6` というモデルIDは存在しない（4-5 系の次は Sonnet 5）。
既定を `claude-sonnet-5` にし、スクリプトプロパティ `CLAUDE_MODEL` で差し替え可能にした。
用途は文面生成のみなので、モデル改定時もプロパティ変更だけで追従できる。

## 2. ルール定義の正を RULES.md ではなく `rules_config.js` に変更

仕様書は「`docs/RULES.md` に人が読める形で管理し、`engine/rules.js` が読み込む」としていたが、
**Markdown を実行時にパースする設計は壊れやすく、表の書き間違い1つで無人発話の判定が変わる。**
「判定は決定論的かつ監査可能」という仕様自身の大原則と矛盾するため、次の形に変えた。

- 正：`gas/engine/rules_config.js`（JSのデータ定義。テストが張り付いている）
- 写し：`docs/RULES.md`（人間向け。変更時は両方更新し、乖離はレビューで検出）

閾値を現場側で日常的に触りたくなった場合は、Phase 2 以降で「スプレッドシートの `rules` シート→
起動時読込＋スキーマ検証」に移行する（Markdownパースには戻さない）。

## 3. フィードバックループの `metric_after_60` は Phase 3 まで空欄

仕様書 §5-B は「発報60分後の指標」を記録するとしているが、**Phase 1 のデータ源は日次の日報のみで、
60分後の指標はそもそも存在しない**（時間帯別データは POS 連携＝Phase 3 から）。
「開店初日から記録を始める」という意図は生かし、次のように実装した。

- 開店前から動くもの：発報記録（日時・ルールコード・タスクID・発報時点の日次指標）、完了記録、発報→完了の分数
- Phase 3 で埋まるもの：`metric_after_60` / `delta`（列だけ先に確保してある）
- それまでの近似：`delta_daily`（当日終了時点の基準比）を参考値として記録

## 4. 死活監視に GAS 外の経路を追加

仕様書は「GASの別トリガーがハートビートを監視」としているが、GASプロジェクト自体が死ぬと
**監視側も一緒に死ぬ**（同一プロジェクト・同一アカウント障害で共倒れ）。補強として：

- display 側でも heartbeat を監視し、20分途絶で画面に「サーバー未接続」を表示（現場が気づける）
- 監視トリガーの通知は LINE に加えて GAS の `MailApp` でも送る（LINEトークン失効時の保険）
- 完全な外部監視（UptimeRobot 等で WebApp を ping）は SETUP.md に手順として記載

## 5. GAS の言語水準

仕様書は「ES2015 相当」だが、現行 GAS は V8 ランタイムで ES2019 相当まで動く。
`const/let`、テンプレートリテラル、アロー関数を通常どおり使う。clasp 管理は仕様どおり。

## 6. 深夜ジョブの日付またぎ

営業が 24時までのため「24:30 の振り返り」はカレンダー上は翌日 00:30。
スケジューラは実時刻 `00:30` で発火し、対象営業日 = 前日 として処理する
（`businessDate()`: 朝6時までは前日扱い）。仕様書に記述がなかったため明文化。

## 7. 客単価の扱い（D-02）

仕様書 §5 の表は「売上 −5%超 かつ 客数ほぼ横ばい」を D-02 とする一方、§5 の定義例は
`avg_check` の −8% を条件にしていて不整合。**表の定義を採用**した：
`売上gap ≤ −5% かつ 客数gap > −5%` → 客単価要因。客単価gapは facts として文面生成に渡す。
（客単価は 売上÷客数 の従属変数なので、独立した閾値を重ねると矛盾ケースが生まれるため）

## 8. Drive の MP3 を「リンクを知っている全員」共有にする

kiosk のブラウザから認証なしで再生するための実装上の要請。音声内容は
guard 通過済みの公開文面のみ（§6-B の「店長スマホのみ」の内容は音声化自体をしない）なので許容。
URL は推測困難なファイルIDに依存する。より固くするなら Phase 2 で Firebase Storage + ルールに移行。
