# Google口コミ 返信テンプレ集(星1〜2向け)

低評価口コミへの返信の下書きに使うテンプレ集。
`◯◯` を埋めて、口コミ内容に1文だけ具体的に触れると「定型文っぽさ」が消えます。

## トーン基準(全テンプレ共通)

- 冒頭は必ず来店への感謝から始める
- 言い訳・反論・お客様への責任転嫁はしない
- 具体的な金銭補償(返金します・無料にします)は書かない
- 個人情報(お客様の名前の推測、来店日時の特定など)には触れない
- 従業員の個人名は出さない
- 長すぎない(4〜6文が目安)
- 締めは「またのご来店」or「貴重なご意見への感謝」

## 返信の基本構成

```
①来店の感謝 → ②不快にさせたことへの謝罪 → ③口コミ内容に具体的に触れる(1文)
→ ④改善・共有の約束 → ⑤締め
```

## 1. 接客への不満

```
この度はご来店いただいたにもかかわらず、スタッフの対応でご不快な思いをおかけし、誠に申し訳ございませんでした。
いただいたご指摘は店舗責任者にも共有し、接客の改善に努めてまいります。
貴重なご意見をありがとうございました。またの機会がございましたら、ぜひお越しくださいませ。
```

## 2. 料理の味・質への不満

```
この度はご来店いただき、ありがとうございました。

貴重なご指摘をありがとうございました。
```

## 3. 提供時間・待ち時間への不満

```
この度はご来店いただき、ありがとうございました。
お料理のご提供までお時間をいただき、大変申し訳ございませんでした。
混雑時の提供体制について、店舗全体で改善に取り組んでまいります。
またの機会がございましたら、ぜひお越しくださいませ。
```

## 4. 価格・量への不満

```

いただいたご意見は、今後のメニューづくりの参考にさせていただきます。
貴重なご意見をありがとうございました。
```

## 5. 店内環境(騒がしい・清掃・においなど)への不満

```
この度はご来店いただき、ありがとうございました。

◯◯につきましては、店舗にて確認し、改善に努めてまいります。
貴重なご指摘をありがとうございました。
```

## 6. 会計ミス・金銭トラブルの訴え 【幹部LINE共有 必須】

```
この度はご来店いただいたにもかかわらず、お会計の件でご迷惑をおかけし、誠に申し訳ございませんでした。
事実関係を確認のうえ、誠意をもって対応させていただきたく存じます。
お手数ですが、店舗(電話番号:◯◯)までご連絡いただけますと幸いです。
```

## 7. 異物混入・体調不良の訴え 【即日 幹部LINE共有 必須】

※返信はこの定型のみ。事実確認前に非を認めきる表現・補償の約束はしない。

```
この度は貴重なご指摘をいただき、ありがとうございます。
ご指摘の内容について、現在店舗にて事実確認を行っております。
ご心配とご不快な思いをおかけしましたことをお詫び申し上げます。
恐れ入りますが、詳しい状況をお伺いしたく、店舗(電話番号:◯◯)までご連絡いただけますと幸いです。
```

## 8. 事実誤認・別店舗との混同と思われるもの

```
ご投稿いただき、ありがとうございます。
恐れ入りますが、ご指摘の◯◯につきまして、当店では◯◯としております。
何かの行き違いがございましたら申し訳ございません。
ご不明な点がございましたら、店舗までお問い合わせいただけますと幸いです。
```

## 9. 内容なし・星だけ・判断不能(汎用)

```
この度はご来店いただき、ありがとうございました。
ご期待に沿えなかった点がございましたら、大変申し訳ございませんでした。
よりご満足いただけるお店を目指して改善を重ねてまいります。
またの機会がございましたら、ぜひお越しくださいませ。
```
