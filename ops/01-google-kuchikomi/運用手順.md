# Google口コミ返信 — 新運用への移行手順と週次トリアージ

## ゴール

- 全件(月約500件)の確認をやめ、**星1〜2(月約50件)だけを人が見る**運用に切り替える
- 月約2時間47分 → 約30〜40分に短縮する

## なぜこれが最適か

- KantaAIは全件自動投稿が可能で、星1〜2だけの絞り込み表示も可能
- 星3〜5の修正率は約3割だが、修正しなくても致命的な問題になるケースはまれ(不自然さの許容)
- 一方、星1〜2は返信の質がそのまま店の印象と再発防止に直結するため、ここに時間を集中するのが費用対効果が最も高い

## 移行チェックリスト(初回のみ)

- [ ] 1. 移行前の最終確認として、直近1週間の自動生成文をざっと見て「絶対に出したくないパターン」がないか確認する
- [ ] 2. KantaAIの自動返信のトーン設定・署名・NGワード設定があれば見直す(`返信テンプレ.md` の「トーン基準」を反映)
- [ ] 3. 幹部LINEに運用変更を一報する(下の定型文を使用)
- [ ] 4. KantaAIで**全件自動投稿をON**にする
- [ ] 5. カレンダーに週1回の「低評価口コミ確認」を固定予定として登録する(所要30分・曜日固定推奨)
- [ ] 6. 移行後1〜2週間は、星3〜5の自動投稿分も週1でランダムに10件ほど抜き取り確認し、問題なければ抜き取りもやめる

### 幹部LINE向け・運用変更の一報(定型文)

```
【Google口コミ返信の運用変更のお知らせ】
これまで全件を目視確認してから返信していましたが、
本日より星3〜5の口コミはAIによる自動返信に切り替えます。
星1〜2の低評価口コミは、これまで通り毎週◯曜日に全件確認し、
内容を修正のうえ返信します。
事実確認や店舗対応が必要なものは、都度このLINEで共有します。
```

## 週次トリアージ手順(毎週◯曜日・約30分)

- [ ] 1. KantaAIで**星1〜2のみ**に絞り込む
- [ ] 2. 1件ずつ、下の「判断フロー」で仕分ける
- [ ] 3. 返信が必要なものは `返信テンプレ.md` から近いテンプレを選んで調整する
   - まとめて処理する場合は、口コミをコピーしてClaude Codeの `/kuchikomi-henshin` に貼り付けると一括で下書きが出ます
- [ ] 4. 社内共有が必要な案件を幹部LINEへ送る(下の共有フォーマットを使用)
- [ ] 5. 全件投稿し終えたら完了

## 判断フロー(星1〜2)

各口コミを上から順に確認し、最初に当てはまったものに従う。

1. **異物混入・体調不良(食中毒疑い)・ケガの訴え**
   → 返信は「事実確認中」の丁寧な定型のみ。**即日、幹部LINEへ共有**(営業・保健所対応に発展しうるため)
2. **会計ミス・金銭トラブルの訴え**
   → 返信で謝罪+店舗への連絡先案内。**幹部LINEへ共有**
3. **従業員の名指し・重大な接客クレーム**
   → 個人名には触れずに謝罪+改善約束の返信。**該当店舗の店長へ共有**
4. **料理の味・量・価格への不満**
   → テンプレ返信(共有不要。ただし同一店舗で同月3件以上続いたら幹部LINEへ)
5. **待ち時間・混雑への不満**
   → テンプレ返信(共有不要。同上)
6. **事実と異なる・誤爆(別の店と間違えている)と思われるもの**
   → 冷静に事実を短く訂正する返信。Googleへの削除申請も検討
7. **内容が薄い・星だけ・判断不能**
   → 汎用テンプレ返信のみ

## 続けるうちに楽になる仕組み

- 修正した返信文のうち「また使えそう」なものは `返信テンプレ.md` に追記していく(テンプレが育つほど修正時間が減る)
- KantaAI側にトーン・NG設定のカスタマイズがあれば、修正が多いパターンを設定に反映して自動生成の精度自体を上げる
