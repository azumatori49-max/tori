# 求人媒体管理 — LINE定型文テンプレ集

毎回ほぼ同じ文章を作っている連絡を定型化。`◯◯`を埋めるだけで送れます。
(`kyujin-tracker.html` を使えば、数字入りの報告文・依頼文は自動生成されます)

---

## 1. 掲載案(幹部グループLINE・承認依頼)

```
【求人掲載のご相談】
以下の内容で掲載を進めたいと考えています。ご確認をお願いします。

■掲載媒体:◯◯
■掲載店舗:◯◯
■プラン:◯◯
■予算:◯◯円
■期間:◯月◯日 〜 ◯月◯日

■背景
・◯◯店の不足人数:◯名
・前回掲載時の実績:応募◯件 / 採用◯名 / 採用単価◯円

問題なければ「OK」の一言で大丈夫です。よろしくお願いします。
```

## 2. 媒体担当者への掲載依頼

```
いつもお世話になっております。
以下の内容で掲載をお願いいたします。

■店舗:◯◯
■プラン:◯◯
■予算:◯◯円
■期間:◯月◯日 〜 ◯月◯日
■原稿:前回と同じ内容でお願いします(変更がある場合:◯◯)

お手数ですが、掲載開始日が確定しましたらご連絡ください。
よろしくお願いいたします。
```

## 3. 集計報告(グループLINE・月2回)

```
【求人応募状況(◯月◯日時点)】
■全体
・応募:◯件(前回比 ◯)
・採用:◯名
・掲載費用:◯円
・採用単価:◯円

■媒体別
・◯◯:応募◯件 / 採用◯名 / 単価◯円
・◯◯:応募◯件 / 採用◯名 / 単価◯円

■所感・次のアクション
・◯◯
```

## 4. バイトル依頼転送フォーマット(担当者宛て)

グループLINEで届いた掲載依頼を転送するときに使用。

```
いつもお世話になっております。
以下の店舗の掲載をお願いいたします。

■店舗:◯◯
■職種:◯◯
■内容:(届いた依頼内容を貼り付け)
■希望開始日:◯月◯日

ご確認のほど、よろしくお願いいたします。
```

## 5. エアワーク スカウト定型文

```
はじめまして。◯◯(会社・店舗名)採用担当です。
プロフィールを拝見し、◯◯のご経験が当店の◯◯のお仕事にぴったりだと思いご連絡しました。
【お店の特徴を1〜2行】
まずはお気軽に、店舗見学だけでも大歓迎です。
ご興味をお持ちいただけましたら、ご返信ください。
```

※差し替えるのは「◯◯のご経験」の部分だけ。あとは固定でOK。

## 6. 媒体担当者への問い合わせ(掲載終了・更新確認)

```
いつもお世話になっております。
◯◯店の掲載についてですが、終了日が◯月◯日と認識しています。
以下についてご確認させてください。
・(継続する場合)同条件で更新は可能でしょうか
・(終了する場合)終了処理をお願いします
よろしくお願いいたします。
```
