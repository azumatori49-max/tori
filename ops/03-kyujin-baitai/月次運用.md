# 求人媒体管理 — 月次運用手順

「複数の管理画面を行き来する」「数字が頭の中とLINEに散らばる」状態をやめて、
**数字は `kyujin-tracker.html` に集約 → 判断・報告・依頼はそこから自動生成**する運用にします。

## 全体の流れ(改善後)

```
各媒体の管理画面(数字を見る場所)
        ↓ 転記(月2回・各5分)
kyujin-tracker.html(数字を貯めて比較する場所)
        ↓ ワンクリック生成
グループLINE報告文 / 掲載案 / 媒体担当者への依頼文
```

## 月2回の集計(月中・月末)— 目標15分/回

- [ ] 1. 各媒体の管理画面で、店舗ごとの「応募数・採用数・掲載費用」を確認する
- [ ] 2. `kyujin-tracker.html` に転記する(採用単価は自動計算されます)
- [ ] 3. 「集計報告文を生成」を押して、グループLINEへ貼り付けて共有する
- [ ] 4. これで集計履歴がツール内に残るので、LINEを遡る必要がなくなります

## 掲載判断(必要な都度)

- [ ] 1. `kyujin-tracker.html` で前月比・媒体別の採用単価を見る
- [ ] 2. 「掲載判断メモ」欄に、店舗ごとの不足人数と判断理由を書く(→頭の中の判断基準が記録として残っていく)
- [ ] 3. 「掲載案を生成」でグループLINE用の掲載案を作り、幹部LINEへ送って承認をもらう
- [ ] 4. 承認後、「依頼文を生成」で媒体担当者へのLINE依頼文を作って送る
- [ ] 5. 掲載期間の終了日をツールの「掲載中リスト」に登録する(終了日が近いものが上に警告表示されます)

## エアワークスカウト(毎日30件・15分)

現状はそのまま継続でOK。ただし以下で少し楽になります。

- スカウト文面は `テンプレ集.md` の「スカウト定型文」を使い回す(対象者の条件に合わせて1〜2文だけ差し替え)
- 送信件数だけを日次でトラッカーの「スカウト記録」につけると、月次報告に自動で含まれます(任意)

## バイトル掲載管理(グループLINE転送業務)

- 届いた依頼をバイトル担当者へ転送する際は、`テンプレ集.md` の「バイトル依頼転送フォーマット」に当てはめて送る(コピペ+穴埋めのみ)
- 掲載中店舗と終了日は `kyujin-tracker.html` の「掲載中リスト」で管理する
  → 開くたびに「終了日まで7日以内」の求人が上部に警告表示されるため、見落としを防げます
