# 応募者対応 — LINE定型文テンプレ集と対応フロー

「似た内容の案内文を何度も送っている」を解消するテンプレ集。
対応状況の見える化は `ops/tools/obosha-board.html` を使ってください(状況に応じたテンプレの自動生成付き)。

## 対応フロー(改善後)

```
①応募が入る → ボードに登録(30秒)
②面接担当者へ可能日を確認(テンプレ1)→ ステータス「担当者確認中」
③応募者へ候補日を提示(テンプレ2)→ ステータス「返信待ち」
④返信が来たら確定連絡(テンプレ3)→ ステータス「日程確定」
⑤返信が2日来なければリマインド(テンプレ4)← ボードが自動で警告表示
⑥面接実施 → ステータス「完了」
```

---

## テンプレ1:面接担当者への日程確認

```
お疲れさまです。◯◯店に応募がありました。
■氏名:◯◯さん
■職種:◯◯
■媒体:◯◯
面接可能な日時を、候補3つほどいただけますか?
(例:◯日◯時〜、◯日◯時〜)
```

## テンプレ2:応募者への候補日提示(初回連絡)

```
◯◯さん
この度は◯◯(店舗名)へご応募いただき、ありがとうございます!
採用担当の◯◯です。
面接の日程について、以下の候補からご都合のよい日時をお知らせください。

①◯月◯日(◯)◯時〜
②◯月◯日(◯)◯時〜
③◯月◯日(◯)◯時〜

上記でご都合が合わない場合は、ご希望の日時をお知らせください。
ご連絡お待ちしております!
```

## テンプレ3:面接日の確定連絡

```
◯◯さん
ご返信ありがとうございます!
それでは面接は以下の日程で確定いたします。

■日時:◯月◯日(◯)◯時〜
■場所:◯◯(住所・地図URL)
■持ち物:◯◯
■当日の連絡先:◯◯

ご不明な点があればお気軽にご連絡ください。
当日お会いできるのを楽しみにしております!
```

## テンプレ4:リマインド(返信が2日ない場合)

```
◯◯さん
先日ご案内した面接日程の件、その後いかがでしょうか?
以下の候補以外でも調整可能ですので、ご都合をお知らせください。
①◯月◯日(◯)◯時〜
②◯月◯日(◯)◯時〜
ご連絡お待ちしております!
```

## テンプレ5:日程再調整

```
◯◯さん
ご連絡ありがとうございます。承知いたしました!
それでは改めて、以下の日程はいかがでしょうか?
①◯月◯日(◯)◯時〜
②◯月◯日(◯)◯時〜
ご都合をお知らせください。よろしくお願いいたします!
```

## テンプレ6:面接前日のリマインド(任意・ドタキャン減に効果的)

```
◯◯さん
明日の面接のご確認です。
■日時:◯月◯日(◯)◯時〜
■場所:◯◯
お気をつけてお越しください。お会いできるのを楽しみにしております!
```

■日時:◯月◯日(◯)◯時〜
