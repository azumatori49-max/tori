# 業務効率化キット

日々の担当業務のうち、優先的に楽にしたい4業務を効率化するための資産一式です。

## 構成

| フォルダ | 対象業務 | 中身 |
|---|---|---|
| `01-google-kuchikomi/` | Google口コミ返信 | 新運用への移行手順、低評価トリアージ手順、返信テンプレ集 |
| `02-gourmet-site/` | グルメサイト管理(食べログ・ホットペッパー) | 更新チェックリスト、サイト別仕様メモ、コース入力ヘルパーツール |
| `03-kyujin-baitai/` | 求人媒体管理 | 月次運用手順、LINE定型文テンプレ集、媒体トラッカーツール |
| `04-obosha-taio/` | 応募者対応 | 対応フロー、LINE定型文テンプレ集、応募者対応ボードツール |
| `tools/` | ミニツール置き場 | ブラウザで開くだけで使えるHTMLツール(インストール不要) |
| `../.claude/skills/` | Claude Code用Skill | 貼り付けるだけで返信文・入力用テキスト・集計報告を生成 |

## ミニツールの使い方

`ops/tools/` の中のHTMLファイルを**ダブルクリックしてブラウザで開くだけ**で使えます。

- インストール・ネット接続・ログイン不要
- 入力したデータはそのPCのブラウザ内(localStorage)に自動保存されます
- 別のPCとはデータ共有されません(1台のPCで使う想定)
- データを消したい場合は各ツール内の「データ削除」ボタンを使ってください

| ツール | 用途 |
|---|---|
| `course-input-helper.html` | コース情報を1回入力 → 食べログ用・ホットペッパー用の2フォーマットを生成。文字数カウント・両サイト整合性チェック・完了報告文の生成付き |
| `kyujin-tracker.html` | 媒体ごとの応募数・採用数・費用を月別に記録 → 採用単価の自動計算、前月比、グループLINE用の集計報告文と掲載依頼文を自動生成 |
| `obosha-board.html` | 応募者の対応状況を一覧管理 → 「返信待ちが2日以上」を自動で警告表示、状況に応じたLINE文をワンクリック生成 |

## Claude Code Skillの使い方

このリポジトリでClaude Codeを開き、以下のように依頼するだけで使えます。

| Skill | 呼び出し方 | できること |
|---|---|---|
| `kuchikomi-henshin` | `/kuchikomi-henshin` の後に口コミを貼り付け | 星1〜2の口コミ(複数まとめてOK)から、テンプレ準拠の返信文を一括生成。社内共有が必要な案件には自動でフラグ |
| `gourmet-course` | `/gourmet-course` の後にコース原文を貼り付け | 幹部LINEで届いたコース文章を、食べログ用・ホットペッパー用に自動で分割・短縮。整合性チェック表と完了報告文もセットで出力 |
| `kyujin-shukei` | `/kyujin-shukei` の後に各媒体の数字を貼り付け | 集計表・前月比・グループLINE用報告文を生成。掲載案や媒体担当者への依頼文の下書きも作成 |
| `obosha-line` | `/obosha-line` の後に応募者情報と状況を伝える | 候補日提示・リマインド・確定連絡・再調整など、状況に合ったLINE文を生成 |

## 期待できる削減効果(目安)

| 業務 | 現在 | 改善後の目安 | 削減 |
|---|---|---|---|
| Google口コミ返信 | 月約2時間47分(500件確認) | 月約30〜40分(低評価50件のみ確認) | 約2時間 |
| グルメサイト管理(コース入力) | 1件約20分 × 月5件 = 約100分 | 1件約8分(生成→貼り付け→確認) = 約40分 | 約1時間 |
| 求人媒体集計 | 月2回 × 30分 = 60分 + 判断の都度確認 | 入力5分×月2回 + 報告文自動生成 | 約40分+判断が速くなる |
| 応募者対応 | 文面作成と状況確認が都度発生 | 定型文コピー+ボードで一目確認 | 対応漏れ・二度手間の削減 |
