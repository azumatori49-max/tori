# らくらく店舗チェック（AM改善チェックアプリ）

店舗巡回チェックリストアプリ。写真撮影＋ワンタップ評価で巡回を記録し、問題点は対応内容・改善期限・担当者まで登録、宿題を次回来店時に自動表示します。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド・サーバー不要）。スマートフォンのブラウザで開くと、写真項目からカメラを直接起動できます。データは端末内（IndexedDB）に保存されます。

```
# ローカルで確認する場合
npx http-server rakuraku-check
```

## 実装済みの仕様

- **基本ルール**
  - 全確認項目で写真の撮影・アップロード必須（項目ごと最大4枚、自動圧縮）
  - 写真に加えて選択式評価（項目ごとに定義された選択肢）
  - 問題がある評価を選ぶと、対応内容・改善期限・担当者の登録が必須になる
  - 未入力・写真未添付があると完了できない（不足一覧からタップでジャンプ）
  - 前回の宿題・タスクを次回来店時に自動表示（ホーム画面＋PDCAの振り返り）
- **チェック項目**
  1. 店舗外観・入口 — 照明・看板・提灯／入口・階段清掃（できなかった場合は理由＋清掃会社依頼の要否→依頼タスク自動作成）
  2. ホール — テーブル清掃／メニュー・コンディメンツ／椅子・客席（不足数・破損数）
  3. キッチン — 冷蔵庫温度（実測温度入力・異常時は報告先も）／まな板・包丁・ダスター（買い替え時は購入タスク自動作成）／フライヤー（清掃＋油の2軸評価）／コンロ／ゴミ置き場
  4. 営業・商品品質 — ピーク帯の現場確認（100点満点の点数＋評価理由）／接客・商品提供（レシピ遵守＋提供状態の2軸）／商品品質
  5. PDCA・社員育成 — 前回宿題の振り返り（完了/一部完了/未完了＋継続）／今回の課題設定／数字確認（売上・人件費率・客単価など、自動計算補助つき）／次回までの宿題（担当者・期限・優先度）
  6. 総合評価・報告 — 店舗名・日時・確認者・全写真・全評価・問題項目・宿題・次回来店日・総合点を自動集計。印刷/PDF保存対応
- **下書き保存** — 入力途中でもブラウザを閉じて再開できます
