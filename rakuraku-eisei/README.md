# らくらく衛生管理

店舗の衛生チェック写真（デイリー7枚・ウィークリー7枚）をスマホから提出し、
管理者がダッシュボードで提出状況を確認できるアプリの **社外提供版** です。

- デザイン・機能は社内版の衛生管理アプリと同一
- 店舗の追加・削除・パスワード管理は **管理者のみ**（サーバー側で強制）
- 通信の瞬断に強い自動リトライ・オフラインキャッシュ内蔵

導入手順は [SETUP.md](./SETUP.md) を参照してください。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # 本番ビルド（型チェック込み）
```
