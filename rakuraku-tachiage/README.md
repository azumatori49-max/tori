# らくらく立ち上げチェック

「立ち上げチェック報告書」スプレッドシートをスマホで使えるようにしたWebアプリです（PWA / ビルド不要の静的サイト）。

## できること

- **店舗一覧** — 52店舗を初期登録。画面上部の検索（店舗名・責任者名）と、件数つきの絞り込み（立ち上げ中 / 決済未完了 / 深夜営業 / 喫煙申請 / 電子 / 要確認）。立ち上げ中の店舗は先頭にまとめて表示
- **立ち上げチェック** — スプレッドシート「鶏ヤロー原本202607」「FC原本」をひな形に、店舗ごとのやることリストを作成。タップで完了、達成率・残り目安時間・オープンまでの日数を表示。**探しやすさ**: 項目名の検索、9つのカテゴリ（届出・契約 / 採用・研修 / 業者・仕入れ / 看板・内装・工事 / 設備・備品 / システム・通信 / 集客・販促 / POP・メニュー / 運営準備）での絞り込み、担当での絞り込み、既定は未完了だけ表示（完了済みは折りたたみ）。日付・担当者・メモの記入、項目の追加・削除
- **届出・許可** — 「食品衛生、防火防災、深夜営業許可」シートの内容（申請方法 / 衛生・防火管理責任者 / クレジット端末 / QRコード・電子 / PAY提出 / 深夜申請 / 深夜営業許可 / 喫煙申請 / 深夜営業許可の必要書類）
- **情報** — オープン日・入居日・工事引渡し日・店長・住所など
- **資料（ホーム右上の本のアイコン。`data.private.js` があるときだけ表示）** — スプレッドシートの共通シートを移したものです。立ち上げの流れ（6ステップ）、業者への連絡内容（13業者・連絡文のひな形をコピー）、新人研修チェック、月末・月初のやること、出店実績（作業日数・時間・坪数と、時間÷坪数の平均との比較）
- バックアップの書き出し/読み込み（JSON）、一覧のCSV書き出し、ホーム画面に追加して使える、圏外でも開ける

## 実データの扱い（重要）

店舗ごとの実データ（店長・担当者の氏名、住所、電話、家賃、チェックリストの進み具合、出店実績）は、公開リポジトリに入れないため `data.private.js` という別ファイルに分けています。このファイルは `.gitignore` で除外してあり、`index.html` が存在すれば読み込みます。

- `data.private.js` あり: 店舗が60件（シートの52件＋立ち上げ中などの8件）になり、20店舗ぶんの進み具合・各店舗の住所や日付が入った状態で始まります
- `data.private.js` なし: ひな形（鶏ヤロー・FC・まる助・業態変更）とシート1の店舗一覧だけで動きます（資料の画面・出店実績は表示されません）
- すでに使っている端末では、保存済みの入力内容を消さずに、足りない店舗の追加・空欄の補完・チェックリストの無い店舗への追加だけを行います
- 公開サイトに置くときは、`data.private.js` を置く場合も置かない場合も、閲覧制限（Vercel の Password Protection や Cloudflare Access など）をかけてください

## 使い方

```bash
cd rakuraku-tachiage
python3 -m http.server 8000   # → http://localhost:8000
# または: npx serve -l 8000 .  # → http://localhost:8000
```

ビルド工程はありません。

## 公開（独自ドメイン）

静的ファイルだけなので Vercel / Netlify / Cloudflare Pages / Firebase Hosting などにそのまま置けます。Vercel の場合は Root Directory を `rakuraku-tachiage` にして、Domains にドメインを追加します。

ドメイン案: **`rakuraku-tachiage.net`**（既存の `rakuraku-kanri.net` と区別しつつ、同じ「らくらく」系に見える名前）。別案は `rakuraku-kanri.com`、`raku2-tachiage.net`。いずれもレジストラで空き状況の確認と取得が必要です。

## 注意

- 入力内容は **各端末のブラウザ内（localStorage）に保存** されます。端末間・メンバー間では共有されません。共有が必要になったらバックエンド（Firebase / Supabase など）の追加が必要です。
- `data.js` に責任者の氏名が入っています。**ログイン機能はない** ので、公開する場合は Vercel の Password Protection や Cloudflare Access などで閲覧を制限してください。`robots` は noindex にしてあります。
- スプレッドシートに書かれていたパスワードやアカウントID、業者の個人メールアドレス・電話番号は **取り込んでいません**。
- 取り込んだ範囲: 食品衛生・防火防災・深夜営業許可（2シート）、鶏ヤロー・FC・まる助・業態変更のひな形、店舗別シートのうちチェックボックスのある21店舗（進み具合つき）と、ヘッダー情報だけの9店舗、立ち上げオペレーション、月末・月初、研修、業者連絡内容表（連絡先を除く）、出店偏差値計算表。
- 取り込んでいないもの: 中身がほぼ空の旧形式の店舗タブ（八戸〜南越谷店など）、古い版のひな形（鶏ヤロー原本・とりちゃん原本）、時間（各項目の目安時間はひな形に含まれています）。
- 元シートの日付に誤りと思われるものがあります（入居日がオープン日より後: 高崎・京都西院・難波）。元のとおり取り込んでいます。
- 初期データ（`data.js`）はスプレッドシートから生成したものです。シートを更新した場合は再生成が必要です。
- チェック項目の9つのカテゴリはスプレッドシートにはなく、探しやすくするために後から付けた分類です。`data.js` の各項目の `c` を書き換えれば変更できます（これから作るチェックリストに反映されます。作成済みのものは、項目の編集画面の「カテゴリ」で変えられます）。
