# Firebase（Google）セットアップ手順

「らくらく店舗メンテナンス」をFirebase（Googleのクラウド）で動かすための手順。
所要時間は15〜20分ほど。ぜんぶブラウザ上の操作だけで完了します。

---

## 1. Firebaseプロジェクトを作る

1. https://console.firebase.google.com を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ プロジェクト名は `rakuraku-maintenance` など好きな名前
3. Googleアナリティクスは「無効」でOK → 作成

## 2. 料金プランをBlaze（従量課金）にする

写真の保存（Storage）に必要です。無料枠が大きいので、当面の請求はほぼ0円です。

1. 左下の「Spark」または歯車 → 「使用量と請求額」→「プランを変更」
2. **Blaze（従量課金）** を選び、クレジットカードを登録
3. 予算アラート（例: 1,000円）を設定しておくと安心

## 3. ログイン機能（Authentication）を有効にする

1. 左メニュー「構築」→「Authentication」→「始める」
2. 「ログイン方法」タブで以下の **2つ** を有効にする:
   - **メール / パスワード** … 有効にして保存
   - **匿名** … 有効にして保存（★閲覧用リンクに必要。忘れずに！）

## 4. データベース（Firestore）を作る

1. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
2. ロケーション: **asia-northeast1（東京）** を選ぶ
3. 「本番環境モード」で作成
4. 作成後、「ルール」タブを開き、中身を**全部消して**
   `firebase/firestore.rules` ファイルの内容を貼り付け →「公開」

## 5. 写真置き場（Storage）を作る

1. 左メニュー「構築」→「Storage」→「始める」
2. ロケーションは Firestore と同じ **asia-northeast1（東京）**
3. 作成後、「ルール」タブを開き、中身を**全部消して**
   `firebase/storage.rules` ファイルの内容を貼り付け →「公開」

## 6. アプリの接続情報を取得する

1. 歯車アイコン →「プロジェクトの設定」→「全般」タブ
2. 下の「マイアプリ」で **ウェブアプリ（`</>` アイコン）** を追加
   - ニックネーム: `web` など。Hostingのチェックは不要
3. 表示される `const firebaseConfig = { ... }` の **中身をまるごとコピー**

## 7. GitHubに接続情報を登録する

1. GitHubのリポジトリ → Settings → Secrets and variables → Actions → **Variables** タブ
2. 「New repository variable」で以下を登録:
   - Name: `EXPO_PUBLIC_FIREBASE_CONFIG`
   - Value: 手順6でコピーした firebaseConfig の中身をそのまま貼り付け
     （`{ apiKey: "...", ... }` の形のままでOK）
3. 登録したら、GitHubの Actions タブから「Deploy Web」を「Run workflow」で実行
   （または何か変更をプッシュすれば自動で走る）

## 8. 動作確認

1. 公開サイトを開く → ログイン画面が表示される
2. 新規登録 → 会社を作成 → レポートを保存
3. 設定 → 閲覧用リンクをコピー → シークレットウィンドウで開いて閲覧できればOK
4. （旧データがある場合）設定 → 「旧システムからの引っ越し」に
   旧アプリの閲覧用リンクを貼り付けて実行

---

### 補足

- 接続情報（firebaseConfig）は公開されても問題ない値です。
  実際のアクセス制御はセキュリティルール（手順4・5）が行います。
- ルールを更新したいときは、コンソールの「ルール」タブに貼り直して「公開」するだけです。
